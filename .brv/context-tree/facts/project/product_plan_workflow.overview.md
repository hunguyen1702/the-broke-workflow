- CLI-guided product planning with 9 subcommands: init, list, docs, read, finalize, plan, status, link, remove
- Product plans stored in .bw/plans/{slug}/ directory with product-plan.md and milestones.md
- Status command shows task progress with visual progress bars (uses _progress_bar helper)
- Uses Click CLI framework in bw/commands/product_cmd.py
- 4 rules: milestone numbers sequential from 1, plan must exist before linking, cannot remove with linked plans without --force, task state tracked via frontmatter (done/in_progress/pending)
- Includes milestone-splitter and milestone-reviewer sub-agents spawned for breaking plans and reviewing milestones
- Helper functions: _parse_milestones, _find_linked_plans, _task_counts, _progress_bar
- Depends on bw.core modules: frontmatter, paths, slug, task_store, templates
- Pattern: `^## Milestone (\d+):\s*(.+)` for milestone headings; `\*\*Goal:\*\*\s*(.+)` for extracting goals
