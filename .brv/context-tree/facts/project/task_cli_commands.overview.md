- The bw task command is a Click group with exactly 12 subcommands for task lifecycle management
- Subcommands include: add-dependency, claim, comment, comments, dag, deps, list, next, release, remove, show, status
- Uses blocked_by dependency where child task depends on parent task
- Status transitions must be validated via validate_transition() function
- All modifications require acquiring lock via acquire() method
- Owner defaults to "unknown" if not specified when claiming a task
- Dependencies: bw.core.frontmatter, bw.core.lock, bw.core.paths, bw.core.task_store modules
