- Step CLI has 5 subcommands: list, show, agent, preamble, spawn
- step list: shows all available steps in a flow
- step show: outputs conductor-level instructions for a step
- step agent: outputs sub-agent instructions for self-bootstrap
- step preamble: outputs conductor rules
- step spawn: outputs Agent tool call for spawning sub-agents with model config
- Accepts step as number or slug (e.g., "2" or "discovery")
- --flow flag selects plan or product flow, --tool flag required for spawn
- Depends on bw.core.steps for rendering functions
